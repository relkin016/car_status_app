# Авто·Статус

Android 10+ (minSdk 29). Офлайн-приложение для контроля состояния транспорта: локальная SQLite-база, без аккаунтов.

- **Гаражи** — несколько гаражей, в каждом несколько транспортов: бензин, дизель, электромобиль, мотоцикл, велосипед, электровелосипед, электросамокат. У каждого вида свой список расходников «из коробки», единицы (л / кВт·ч), квесты и советы; OBD2 — только у авто и мото. Переключение — по строке под заголовком любой вкладки. Уведомления приходят сразу по всем гаражам (в каждом можно выключить), нажатие открывает нужный транспорт. У каждого транспорта своя база (`car.db` — первый, `vehicle_<id>.db` — остальные), реестр — `garage.json`.

- **Статус** — «здоровье» авто и каждого узла как шкалы жизней (HP). У пункта ТО два лимита — по пробегу и по времени; показывается тот, что сработает раньше, с прогнозной датой по среднему пробегу.
- **Журнал** — заправки, ТО, запчасти, расходы, дневник инцидентов (дата+время+пробег), фото, показания одометра.
- **Расходы** — реальная цена километра: (топливо + ТО + запчасти + прочее) ÷ км за период, расход л/100 км, по месяцам.
- **OBD2** — ELM327 по Bluetooth: коды ошибок с расшифровкой и подсказками, сброс, датчики, пробег (PID A6 или оценка по PID 31).
- **Шины** (авто и мото) — комплекты летние / зимние / всесезонные: размер, DOT (возраст), протектор, где хранятся. Переобувка с датой и пробегом (стоимость шиномонтажа — в журнал как «Работы»), пробег каждого комплекта, предупреждения: протектор ниже нормы, резине 6+ лет, стоят не по сезону.
- **Автокопия** — тот же zip, что и экспорт, раз в день / неделю / месяц в выбранную папку (SAF); хранится N последних (`carstatus-auto-*.zip`), ручные копии не трогаются. Делается при ежедневной проверке или при запуске, если пропущена; об ошибке — уведомление.
- **Ещё** — профиль авто, редактор пунктов ТО, список поломок (чек-лист), сезонные квесты, история для покупателя и выписка расходов (Markdown), экспорт/импорт (zip: все гаражи, базы и фото; копии 0.1 тоже читаются), «поделиться APK», настройки.
- **Уведомления** (каждое: выкл / уведомление / будильник): HP ниже порога (20%), напоминание ввести пробег (раз в N дней, в поле — текущий пробег и калькулятор), сезонные квесты, когда выгодно покупать вне сезона, шины, ошибка автокопии, напоминание внести расходы (ежедневно / еженедельно — в воскресенье / ежемесячно — в последний день месяца; уведомление открывает меню «Добавить»).
- **Тема**: системная / светлая / тёмная / AMOLED (чисто чёрный фон).

## Сборка

```
ci/remote_build.sh   # сборка на ноде, APK → dist/ и ~/Downloads (с проверкой SHA-256)
ci/release.sh ["что нового"]   # сборка + MEGA (2 версии) + site/release.json + push + Discord
```
Сайт — `site/` (GitHub Pages, https://relkin016.github.io/car_status_app/). Для MEGA нужен venv с `ci/requirements-mega.txt` (по умолчанию `~/.venvs/wallet-mega`).
Версия — `appVersion` в `app/build.gradle.kts`. Ключ подписи — `keystore/` (вне git).
